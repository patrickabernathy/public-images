# Houseplants

Images for the midterm houseplants API (`/webhook/midterm-site-team1/houseplants` on n8n.aseglave.net). There is one folder per Perenual plant id, with up to five sizes each: `original.jpg`, `regular.jpg`, `medium.jpg`, `small.jpg` and `thumbnail.jpg`.

Downloaded from [Perenual](https://perenual.com/docs/api) on 2026-09-29. Only the 135 plants whose images are on Perenual's free plan are here. The photos are Creative Commons licensed, and each plant's `default_image.license_name` and `license_url` in the API data give the license and attribution terms.

Link to them with `https://raw.githubusercontent.com/patrickabernathy/public-images/main/houseplants/<id>/<size>.jpg`.
